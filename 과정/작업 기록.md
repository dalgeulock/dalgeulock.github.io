# 작업 기록

클로드 코드 세션에서 한 일을 순서대로 적었어요. 대화 원본은 개인 정보가 섞여 있어 빼고 요약만 남겼어요.

## 2026-10-27 · 1차: 피그마 → 웹, 인터랙션

**요청:** 피그마 6개 화면을 웹 버전으로 만들고, 페이지와 모든 버튼에 스마트 애니메이트 같은 인터랙션을 걸기.

1. **피그마 읽기**
   - 피그마 MCP로 6개 프레임을 확인했어요.
   - 프레임 ID: HOME `1:2`, ABOUT `1:245`, RESEARCH `1:304`, EXPERIMENT `1:538`, DESIGN `1:870`, BRAND `1:701`
   - 모두 가로 1080px이에요. 세로는 화면마다 3594~5480px이에요.
2. **코드 뽑기:** 각 프레임의 `get_design_context` 결과(React + Tailwind, 절대 좌표)를 `과정/jsx/`에 저장했어요.
3. **변환 (`과정/convert.py`)**
   - JSX를 일반 HTML로 바꿨어요(className → class, 이미지 주소를 `assets/`로).
   - 피그마 이미지 79개(약 69MB)를 내려받았어요. 화질은 원본 그대로예요.
   - 피그마의 `Noto_Sans_KR` 글꼴 지정은 지우고, 전체에 Noto Sans KR(구글 폰트)을 걸었어요.
4. **화면 배치**
   - 피그마 좌표를 그대로 두고, 1080px 판을 화면 폭에 맞춰 CSS `zoom`으로 키웠어요.
   - 그래서 피그마와 픽셀 단위로 같아요.
5. **헤더**
   - 화면마다 있던 상단 메뉴를 숨겼어요.
   - 같은 좌표로 화면 위에 고정되는 헤더를 새로 만들었어요.
6. **인터랙션 (`과정/src/site.js`)**
   - 페이지 이동은 View Transitions로 해요.
   - 누른 요소와 다음 페이지 요소에 같은 `view-transition-name`을 붙여서, 하나가 이어서 움직이는 것처럼 보이게 했어요.
   - 마우스 반응은 글자가 겹쳐 있어도 동작하도록, 마우스 좌표로 '반응 영역'을 판정해요.
   - 누를 수 있는 곳(목차, NEXT, 카드, 색 견본)은 투명 버튼을 위에 깔았어요.
   - 카드는 바탕 면 안에 들어간 글자·선을 찾아 한 덩어리로 묶어요.
7. **확인**
   - 브라우저에서 전환을 10배 느리게 돌려 도중 장면을 찍었어요. 목차 강조 면, 도면 링, 브랜드 심볼 회전도 확인했어요.
   - 맨 아래 줄이 안 떠오르던 문제를 고쳤어요(스크롤 감지 범위).
8. **AI 티 점검:** 긴 줄표(—) 20곳이 걸렸어요. 팀이 쓴 피그마 문구라 그대로 두고, 파일 맨 위에 예외로 표시했어요.

## 2026-10-27 · 3차: 움직임 줄이기, 깃허브 배포

**요청:** 과한 인터랙션, 특히 확대되는 움직임을 빼기. 깃허브로 팀에 공유하기.

| 바꾼 것 | 전 | 후 |
|---|---|---|
| 사진에 마우스 올림 | 1.045배 확대 + 밝게 | 확대 없이 조금 밝게 |
| 브랜드 점·원 아이콘 | 1.7배 / 1.14배 확대 | 움직임 없음 |
| 브랜드 축 아이콘 | 90° 회전 | 움직임 없음 |
| 브랜드 선 아이콘 | 줄어들고 점이 25px 이동 | 점만 8px 모임 |
| 아침·점심·저녁 점 | 1.8배 확대 | 색만 바뀜 |
| 홈 지구 | 떠다니며 기울고 마우스 따라 움직임 | 4px만 천천히 떠 있음 |
| 카드 들림 | 4px | 2px |
| 글자 밀림(목차·NEXT) | 8~10px | 3~4px |
| 스크롤 떠오름 | 18px | 10px |
| 페이지 전환 | 위아래 26px | 12px |
| 큰 화면 확대 상한 | 1.6배 | 1.25배 |

- + ↔ × 심볼 회전과 페이지 사이 이어지는 전환(스마트 애니메이트)은 남겼어요.
- 화면을 그리지 못하는 상태(백그라운드 탭 등)에서 페이지 이동이 멈추던 문제를 고쳤어요. 0.5초 안에 전환이 시작되지 않으면 바로 넘어가요.
- 결과물 이름을 `index.html`로 바꾸고 깃허브 Pages로 배포했어요.
