# 달그락 웹사이트

무중력 환경의 식사 경험을 위한 식기 디자인 졸업작품 「달그락(DAL GEU LOCK)」의 아카이브 사이트예요.
피그마 6개 화면(HOME·ABOUT·RESEARCH·EXPERIMENT·DESIGN·BRAND)을 웹으로 옮기고 인터랙션을 걸었어요.

- 사이트: https://dalgeulock.github.io/
- 피그마 원본: https://www.figma.com/design/hzlLLecnCStnVFEUHrllo6/Untitled?node-id=0-1
- 지금까지 한 일: [과정/작업 기록.md](과정/작업%20기록.md)
- 팀원이 직접 고치는 법: [팀원 수정 가이드.md](팀원%20수정%20가이드.md)
- 다른 맥북에서 클로드 코드로 이어 할 때: [다음 세션 프롬프트.md](다음%20세션%20프롬프트.md)

## 바로 보기

```bash
git clone https://github.com/dalgeulock/dalgeulock.github.io.git
cd dalgeulock.github.io
python3 -m http.server 4897
```

브라우저에서 http://localhost:4897 을 열어요. 글꼴(Noto Sans KR)과 Tailwind를 인터넷에서 불러오니 인터넷 연결이 필요해요.

## 폴더 구조

| 위치 | 내용 |
|---|---|
| `index.html` | 완성된 사이트 한 장. **직접 고치지 않아요.** `과정/build.py`가 만들어요 |
| `assets/` | 피그마에서 내려받은 이미지 79개 |
| `과정/src/site.css` | 헤더·움직임·전환 스타일 |
| `과정/src/site.js` | 페이지 이동과 모든 인터랙션 |
| `과정/src/shell.html` | 페이지 껍데기(헤더, 글꼴, 스크립트 자리) |
| `과정/jsx/` | 피그마 MCP가 뽑아 준 화면 코드 원본 6개 |
| `과정/pages.json` | jsx를 HTML로 바꾼 결과 (convert.py가 만듦) |
| `과정/convert.py` | jsx → HTML 변환 + 이미지 내려받기 |
| `과정/build.py` | 껍데기 + CSS + JS + 화면을 합쳐 `index.html` 만들기 |

## 고치는 순서

1. **움직임·헤더만 고칠 때:** `과정/src/`의 파일을 고치고 `python3 과정/build.py`를 실행해요.
2. **피그마 디자인이 바뀌었을 때:** 피그마 MCP로 해당 프레임 코드를 다시 뽑아 `과정/jsx/`에 덮어써요. 그다음 `python3 과정/convert.py .`, `python3 과정/build.py`를 차례로 실행해요.
   - 피그마 MCP의 이미지 주소는 7일 뒤 만료돼요. 새로 뽑은 코드로 convert.py를 돌려야 새 이미지가 내려받아져요.
3. 고친 뒤 `git push` 하면 1~2분 뒤 사이트에 반영돼요.
   - `과정/` 아래 파일이 바뀌면 깃허브가 `index.html`을 자동으로 다시 만들어요(`.github/workflows/build.yml`).
   - 그래서 깃허브 웹에서 `과정/jsx/` 글자만 고쳐도 사이트에 반영돼요.

## 인터랙션 목록

- **페이지 전환 (스마트 애니메이트):** 누른 글자(목차 줄, 각 페이지 맨 아래 NEXT 제목)가 다음 페이지 큰 제목 자리로 이어서 움직여요. 홈의 숟가락·가위·트레이 카드는 사진이 디자인 페이지의 해당 사진 자리로 옮겨가요. 브라우저의 View Transitions 기능을 써요(크롬·사파리 18 이상·엣지).
- **헤더:** 화면 위에 고정돼요. 메뉴에 올리면 붉은 밑줄이 그 메뉴로 미끄러져요. ARCHIVE는 "준비 중이에요"가 떠요.
- **홈:**
  - 지구와 손글씨 로고가 천천히 떠 있어요.
  - 왼쪽 세로선이 읽은 만큼 내려가요.
  - 아침·점심·저녁에 올리면 해당 표시가 초록으로 바뀌어요.
  - 오리온 도면 설명 A~D에 올리면 도면 위 링이 해당 지점으로 옮겨가요.
  - 목차 강조 면이 마우스를 올린 줄로 따라가요.
- **카드:** 마우스를 올리면 면과 글자가 2px 올라오고 윗선이 붉어져요. 사진은 조금 밝아져요.
- **브랜드:**
  - + 심볼은 45° 돌아 ×가 되고, ×는 +가 돼요.
  - 선 요소의 두 점이 가운데로 모여요.
  - 색 견본을 누르면 색 코드가 복사돼요.
- **스크롤:** 요소가 왼쪽부터 차례로 떠올라요.
- **움직임 줄이기:** 운영체제의 '동작 줄이기' 설정이 켜져 있으면 움직임이 모두 꺼져요.

## 알려진 한계

- 1080px 화면 기준이에요. 좁은 화면(휴대폰)에서는 통째로 작아져 보여요.
- ARCHIVE 페이지는 피그마에 없어서 만들지 않았어요.
- 큰 화면에서는 최대 1.25배까지만 키워요.
